## Pages
| Path | Job | Action |
|---|---|---|
| `/` | Say what this is and send the reader to the one area | Open Bugis / City Hall |
| `/bugis-city-hall/` | List every spot near the two stations with the socket line first | Open a spot, or suggest a spot |
| `/bugis-city-hall/<spot>/` | Answer "will I get a socket, is it quiet, when does it close" with sources, and take a suggestion | Send suggestion |
| `/api/suggestions/<spot>` | GET the list, POST a new one | — |

## The spot page, top to bottom
1. Back link to the area.
2. Name, kind and address.
3. Fact list: Sockets, Wi-Fi, Noise, Hours, Food. Each row: the value in ink, a status chip (reported with the report count
   in ink, source name for hours, "Not reported yet" in the unknown colour). An unknown row still appears; the gap is the
   product's honesty.
4. "What people added" — suggestions, newest first, relative date, no names.
5. The form: one textarea, "Send suggestion". Under it: "No account needed. It appears here once sent."
6. Footer credit.

## Tokens (locked in `src/styles/tokens.css`, gated by `scripts/check-tokens.mjs`)
Colour: paper, ink, blue (actions only), white (card), muted, ok, warn, unknown, bad. Type scale 13 / 15 / 17 / 21 / 26 / 32.
Spacing 4 / 8 / 12 / 16 / 24 / 32 / 48. Memphis fills by kind: yellow libraries, pink malls, teal cafés, white otherwise; ink text only on a fill.
The style layer: radius 0, 3px ink borders, 4px hard shadow, sentence-case labels, a dotted tray behind the list.

## Suggestions
- POST body: `spot`, `text` (10–280 chars), `website` (honeypot, must be empty). Stored as
  `{ id, text, at }` in KV key `suggestions:<spot>`, newest first, capped at 200 per spot.
- Rate limit: 5 per IP per hour via a KV counter with TTL. Over the limit returns 429 with a plain sentence.
- No HTML rendered from user text; everything is escaped.
- Deleting one: edit the KV key in the Cloudflare dashboard (hand-editable, like the seed).

## Not built, with reasons
Maps (a third-party tile load per page, and the address plus station is enough to walk); search (seven spots); photos
(rights and people); ratings (the brief forbids ranking); moderation UI (edit KV by hand until volume says otherwise).
