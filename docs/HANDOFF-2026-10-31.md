## Waiting on Joshua

   runs `npm run deploy`, or the repo connected in the Cloudflare dashboard (build `npm run build`, output `dist`, KV
   binding `SUGGESTIONS`). Then the two CNAME records in `docs/DEPLOY.md`. Until then the suggestion box on the Netlify
   site says "Suggestions are not switched on at this address yet."
2. **Merging PR #1.** Merging puts the Memphis site on studyspots.org through Netlify straight away; suggestions follow
   on the Cloudflare day.
3. **Two NLB facts.** nlb.gov.sg blocked every automated read with a bot challenge. The National Library Building's
   address and hours, and library@esplanade's hours, show as unverified. A person with a browser fills them in
   `data/spots.json` (hours `status: "reported"` with `text` and `source`; address `verified: true` with `source`).
4. **The second Netlify project.** Two Netlify projects build every push; on a credit-based Netlify plan each production
   deploy costs credits, so delete the one that does not serve the domain.

## Known limits of v0
- Suggestions have no moderation UI: delete by editing the KV value `s:<slug>` in the Cloudflare dashboard.
- KV allows 1,000 writes a day on the free tier; each suggestion is two writes.
- "Open now" is deliberately not a filter: it would print an hour the site computed rather than one a page states.
